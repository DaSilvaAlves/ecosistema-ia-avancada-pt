## User Story

Como Eurico, quero que qualquer push para `main` ou abertura de PR dispare automaticamente lint + typecheck + tests em GitHub Actions e faça deploy para `nexus-eurico.vercel.app`, para que o Epic 0 seja considerado completo com infraestrutura de entrega contínua funcional — verificável por mim na URL pública.

---

## Acceptance Criteria

- **AC1:** Ficheiro `.github/workflows/nexus-v2-ci.yml` existe. Em qualquer `push` ou `pull_request` que toque `imersao-tools/nexus/v2/**`, o workflow executa 3 jobs em paralelo: `lint-typecheck` (ESLint + `tsc --noEmit`), `unit-tests` (Vitest com coverage), `e2e` (Playwright Chromium). Todos os jobs devem passar antes de merge em `main`.
- **AC2:** Job `lint-typecheck` corre `npm ci --prefix imersao-tools/nexus/v2` + `npm run lint --prefix imersao-tools/nexus/v2` + `npm run typecheck --prefix imersao-tools/nexus/v2` e falha com exit code não-zero se qualquer um falhar.
- **AC3:** Job `unit-tests` corre `npm run test:unit --prefix imersao-tools/nexus/v2 -- --coverage` e faz upload do relatório para Codecov (ou guarda como artefacto GitHub Actions se Codecov não estiver configurado). Job falha se qualquer teste falhar.
- **AC4:** Job `e2e` instala Playwright (`npx playwright install --with-deps chromium`), inicia a app em background (`npm run build && npm run start`), corre `npm run test:e2e --prefix imersao-tools/nexus/v2`. Job inclui o teste E2E que verifica AC4 do PRD Epic 0: "API key Anthropic NÃO aparece no bundle do client" — grep ao output de `next build` confirma ausência de `sk-ant-`.
- **AC5:** Vercel está configurado para detectar `imersao-tools/nexus/v2/` como root directory do projecto Nexus. Cada PR abre deploy preview com URL única. Push em `main` faz deploy em produção para `nexus-eurico.vercel.app`. URL de produção responde com redirect para `/login` (HTTP 200 ou 302) — verificável manualmente após deploy.
- **AC6:** `v2/vercel.json` (ou configuração equivalente) define `framework: "nextjs"`, `rootDirectory: "imersao-tools/nexus/v2"` para que o Vercel construa apenas esta subpasta (não o repo raiz).
- **AC7:** Variáveis de ambiente no Vercel estão configuradas conforme `architecture-v2.md §9.2` — pelo menos `ANTHROPIC_API_KEY`, `NEXUS_PASSWORD_HASH`, `KV_REST_API_URL`, `KV_REST_API_TOKEN`, `SESSION_SECRET` devem existir no projecto Vercel (Eurico configura manualmente via Vercel UI usando `.env.example` como guia).
- **AC8:** `npm run build` executado localmente dentro de `v2/` passa sem erros TypeScript nem warnings de lint (gate final antes de push). Confirmar Lighthouse score >= 80 mobile no deploy de produção (PRD Epic 0 AC6).

## Dev Notes

- **Workflow GitHub Actions:** `architecture-v2.md §13` — esboço YAML completo. Adaptar `--prefix` para paths relativos ao root do repo (`imersao-tools/nexus/v2`).
- **Paths filter CI:** usar `on.push.paths` e `on.pull_request.paths` com `['imersao-tools/nexus/v2/**']` para não disparar CI em cada commit noutros projectos do mono-repo.
- **Vercel rootDirectory:** Vercel suporta `rootDirectory` em `vercel.json` — necessário porque o repo tem múltiplos projectos. Alternativa: configurar via Vercel Dashboard → Settings → Root Directory → `imersao-tools/nexus/v2`.
- **Domínio Vercel:** `nexus-eurico.vercel.app` — decisão G2 fechada em 04/05/2026. O domínio default Vercel é atribuído automaticamente ao criar o projecto; confirmar que coincide.
- **Env vars Vercel:** `architecture-v2.md §9.2` — tabela completa de 12 vars. Eurico configura manualmente via Vercel UI. Dev deve deixar `.env.example` completo como referência. Nunca commitar valores reais.
- **API key grep:** PRD Epic 0 AC4 — "API key Anthropic NÃO aparece no bundle do client". CI verifica com grep. String a procurar: `sk-ant-` (prefixo standard das Anthropic keys). Se aparecer em `.next/static/`, build falha com exit code 1.
- **Lighthouse:** PRD Epic 0 AC6 — score >= 80 mobile. Correr após deploy de produção. Ferramentas: Lighthouse CLI (`npm install -g lighthouse`) ou Lighthouse CI (`npx lhci autorun`). Resultado documentado no handoff de saída.
- **CodeRabbit:** `architecture-v2.md §13` — CI inclui job `coderabbit` para PRs. Configurar opcionalmente — não bloqueia Epic 0 se não estiver pronto.
- **Nota de coordenação:** esta story pode ser configurada em paralelo com stories 0.4-0.8 (não precisa de código funcional para configurar CI e Vercel). O deploy preview estará vazio até 0.4/0.6 mas o pipeline CI deve estar verde.
