- **AC1 — Helper puro `lib/habitos/heatmap.ts` (range):** Existe `v2/lib/habitos/heatmap.ts` exportando `getLast6MonthsRange(todayISO: string): { from: string; to: string }`. Comportamento: `to === todayISO`; `from` = a segunda-feira da semana situada 25 semanas antes da semana que contém `todayISO` (⇒ 26 semanas/colunas no total, alinhadas a segunda-feira). Entrada e saída em `YYYY-MM-DD`. Função pura e determinista (nenhum `Date.now()`/`new Date()` sem argumento — recebe `todayISO`). _Trace: FR26, [AUTO-DECISION] A4/A5._

- **AC2 — Helper puro `buildHeatmapGrid` (grelha):** `v2/lib/habitos/heatmap.ts` exporta `buildHeatmapGrid(logs: HabitLog[], range: { from: string; to: string }): HeatmapWeek[]` com os tipos:
  ```ts
  export interface HeatmapDay {
    date: string;        // YYYY-MM-DD
    completed: boolean;  // existe ≥1 HabitLog nesse dia
    inRange: boolean;    // false em células de padding (fora de [from, to])
  }
  export interface HeatmapWeek {
    days: HeatmapDay[];  // sempre 7 entradas, de segunda (índice 0) a domingo (índice 6)
  }
  ```
  Comportamento:
  - Cada `HeatmapWeek` tem **exactamente 7 dias** (segunda→domingo). As células fora de `[from, to]` (padding inicial da 1.ª semana e final da última) têm `inRange: false` e `completed: false`.
  - `completed === true` num dia sse existe pelo menos um `log` em `logs` com `log.date === day.date`. Dedup-safe (vários logs no mesmo dia → na mesma `completed: true`, sem erro).
  - Logs com `date` fora de `[from, to]` são **ignorados**.
  - A grelha é ordenada por semana ascendente (mais antiga → mais recente, esquerda→direita) e por dia dentro da semana (segunda→domingo).
  _Trace: FR26, AC1 epic, [AUTO-DECISION] A1/A4/A5._

- **AC3 — Componente `HabitHeatmap` (presentacional + a11y):** Existe `v2/components/habitos/HabitHeatmap.tsx`. Props: `logs: HabitLog[] | undefined`, `todayISO: string`. Constrói o range com `getLast6MonthsRange(todayISO)` e a grelha com `buildHeatmapGrid` (AC1/AC2). Renderiza uma grelha CSS (sem nova dependência — CSS grid) de colunas=semanas × 7 linhas=dias. Requisitos a11y (**não-só-cor**, A1 Epic 2):

  - Pista **não-só-cor**: célula concluída = preenchimento sólido (Lime `#39FF14`); não-concluída = contorno/glassmorphism subtil (`rgba(255,255,255,0.05)`). A distinção é de **preenchimento (forma)**, não só de matiz.

  Design system: fundo `#04040A`, glassmorphism, Inter (texto) + JetBrains Mono (datas/números), paleta fixa. _Trace: FR26, `design-system-ia-avancada.md`, A1 Epic 2 (a11y não-só-cor), [AUTO-DECISION] A2._
