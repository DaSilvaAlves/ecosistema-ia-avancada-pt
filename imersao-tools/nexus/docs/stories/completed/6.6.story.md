## User Story

Como Eurico (utilizador do Nexus), quero poder dizer "amanhã 15h reunião com Paulo" ao cérebro do Nexus e que o evento seja criado automaticamente no meu calendário, para que eu nunca tenha de abrir o Google Calendar manualmente para gerir a minha agenda.

    name: 'criar_evento_calendar',  // ASCII puro — TOOL_NAME_PATTERN /^[a-z][a-z0-9_]*$/
    description: 'Cria um evento no calendário. Exemplos: "amanhã 15h reunião com Paulo", "sexta 3ª reunião equipa".',
    domain: 'calendar',
    requiresPreview: true,    // efeito externo indirecto via push 6.4 — D-6.6-PREVIEW

      title: z.string().min(1, 'título obrigatório'),

      endAt: z.number().int().positive(),     // epoch ms
      allDay: z.boolean().optional().default(false),
      description: z.string().optional(),
    }),
    resultSchema: z.object({
      id: z.string(),
      title: z.string(),
      startAt: z.number(),
      endAt: z.number(),
      allDay: z.boolean(),

      const { title, startAt, endAt, allDay = false } = args;
      if (!allDay && endAt <= startAt) {

      }

        id,
        title,
        startAt,
        endAt,
        allDay,
        updatedAt: Date.now(),
        // googleId: ausente → classe "local-pendente" → route push 6.4 identifica
      };
      await ctx.db.calendarEvents.add(event);
      return { id, title, startAt, endAt, allDay };
    },
  })
);
