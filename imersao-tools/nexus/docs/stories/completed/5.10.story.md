### `searchNotes` JÁ EXISTE mas tem as mesmas limitações da `searchJournalEntries` pré-5.5

**`searchNotes` em `v2/lib/db/repos/knowledge-notes.ts:76-85`:**

```ts
export async function searchNotes(query: string): Promise<KnowledgeNote[]> {
  const needle = query.trim().toLowerCase();
  if (needle === '') return [];
  const all = await db.knowledge_notes.toArray();
  return all
    .filter((note) =>
      `${note.title} ${note.bodyMarkdown}`.toLowerCase().includes(needle),
    )
    .sort((a, b) => b.updatedAt - a.updatedAt);
}
```

Docstring explícito: *"Base que a Story 5.10 (pesquisa full-text conhecimento) refina."* Limitações idênticas à `searchJournalEntries` pré-5.5:

| Limitação | Impacto | Correcção na 5.10 |
|-----------|---------|------------------|
| Single-needle concatenado | `"aprendi React"` não bate se termos estão separados | Tokenização multi-termo (AND) |
| Sem normalização diacríticos | `"area"` não bate `"área"` nos títulos | NFD + remoção de combinantes |
| Haystack incompleto | `sourceUrl` não pesquisável | Incluir `sourceUrl` no haystack |
| Lógica inline no repo | Não testável sem Dexie | Extrair para helper puro `lib/conhecimento/pesquisa.ts` |

## User Story

Como utilizador do Nexus (o Eurico), quando estou na página de Conhecimento, quero poder pesquisar nas minhas notas por palavras ou expressões — e ver os resultados com o breadcrumb área/caderno e um excerto com o termo destacado — para que consiga encontrar rapidamente o que escrevi sobre um tema específico sem navegar manualmente pela hierarquia.
