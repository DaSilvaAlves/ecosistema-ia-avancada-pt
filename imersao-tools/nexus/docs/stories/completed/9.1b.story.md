## Story

**As a** equipa de desenvolvimento do Nexus v2,
**I want** que o relatório de cobertura de testes (`npm run test:coverage`) meça pela primeira vez todo o package finanças (`lib/financas/**` + `app/(app)/financas/**` + `components/financas/**`) — hoje quase totalmente fora do allowlist apesar de ser um domínio de produção completo desde o Epic 3 — e que atinja ≥60% depois dos testes mínimos necessários,
**so that** o gate de cobertura (NFR17) deixe de esconder ~6.145 linhas de UI financeira (10 componentes CRUD + 3 páginas) nunca antes testadas, sem misturar esse esforço maior com a correcção de baixo risco das rotas proxy (isolada em 9.1a).
