## Nota do `@sm` River

### Origem (bug de produção verificado em código)

30/05/2026 — o Eurico escreveu "anota a tarefa de comprar pão" em produção (`imersao.ia.expressia.pt`). Resultado:

```
criar_tarefa falhou — Cannot read properties of null (reading 'tasks')
```

**Causa raiz (verificada no código real, não suposição):**

| Facto | Evidência |
|-------|-----------|
| O executor corre server-side (Edge) e injecta `db = null` de propósito | `lib/agent/executor.ts:416` — `db: null as unknown as NexusDB` + comentário "Edge runtime NÃO tem IndexedDB" |
| As 12 tools chamam `ctx.db.*` directamente | `lib/agent/tools/tasks.ts:198,220,244,281,327,368` (`ctx.db.tasks/projects`), idem `finance.ts`, `projects.ts` |
| O padrão "command" (server emite, cliente aplica) que evitaria isto **nunca foi implementado** | `executor.ts:415` — `@todo Stories 2-7 ... devem devolver commands` (aberto) |
| O cliente (`useAgentStream`) **já persiste o chat-log** (agent_runs, chat_messages, tool calls) mas **nunca cria a entidade de domínio** | `hooks/useAgentStream.ts:107-123` persiste `ToolCall` metadata; nunca chama `db.tasks.add` |

**Tradução:** o chat classifica e responde, mas a persistência de domínio (criar Task/Transaction/etc.) e as leituras (`listar_tarefas`) falham porque `ctx.db` é `null` no servidor.

### Decisão arquitectural (ADR-9 — Aria)

`architecture-v2.md` ADR-9 decidiu **mover o tool-calling loop para o cliente**, com `ctx.db` = instância Dexie real, mantendo o Edge **só** com `/api/anthropic/proxy` (segredo da API key + streaming). Razão: as **tools de leitura** (`listar_tarefas`, `listar_atrasadas`, `consultar_balanco`, `consultar_categoria`, `consultar_projecto`) precisam de **dados reais re-injectados no LLM a meio do loop** (`executor.ts:937 messages.push(tr)`) — o command pattern só serviria escritas. Num app local-first single-user, orquestra-se onde a data vive (o browser).

### Insight central de scope (reduz o risco)

**As 12 tools NÃO mudam.** Já usam `ctx.db.*` — só precisam que `ctx.db` seja Dexie real. A mudança é cirúrgica na **orquestração**: onde corre o loop e como faz inferência (proxy em vez de SDK directo) + de onde vêm `db`/confirmação/undo.

### `mock-protocol-fidelity.md` — CRÍTICO nesta story

A story muda **onde** o protocolo Anthropic é consumido (cliente → proxy). Os mocks têm de reflectir o protocolo SSE real da Anthropic na fronteira do proxy (ADR-8 mantém-se: `page.route()` em `/api/anthropic/proxy`). Qualquer mock do transport client-side **espelha o wire format real** (eventos `content_block_delta`/`input_json_delta`/`message_stop`), com ≥1 teste que falharia se divergisse — é exactamente o incidente da Story 1.2.

## Acceptance Criteria

> Trace: ADR-9, PRD §6.1 FR1-FR6, NFR11 (sem prompt em claro nos logs), NFR15 (TS strict), NFR17 (cobertura ≥60%), NFR18 (CodeRabbit CRITICAL bloqueia), `mock-protocol-fidelity.md`, `separation-of-roles.md`.

- **AC1 — Executor injectável:** `runAgent` (ou equivalente) aceita um `ExecutionContext` (ou factory) injectado com `db`, transport de inferência, `confirmationProvider` e `undoStore`. Deixa de construir um `ctx` server-fixo com `db: null`. O `toolCallingLoop` e as 12 tools permanecem inalterados na lógica. _Trace: ADR-9, A1, R1/R3._

- **AC2 — Transport de inferência via proxy:** existe um transport client-side que faz `fetch('/api/anthropic/proxy', { stream: true })` para classifier (Haiku) e executor (Sonnet). A `ANTHROPIC_API_KEY` **não** é referenciada em nenhum módulo `'use client'`. _Trace: ADR-9, A2/A6, §9.2._

- **AC3 — `ctx.db` real no cliente:** o executor client-side injecta `db` de `@/lib/db/client` (Dexie). Uma chamada a `criar_tarefa` cria mesmo um registo em `db.tasks`. **Zero `Cannot read properties of null`.** _Trace: ADR-9, R3._

- **AC4 — `useAgentStream` conduz o executor client-side:** o hook deixa de fazer `fetch('/api/agent/prompt')` e passa a conduzir o executor no browser, emitindo a mesma sequência de `ExecutorSSEEvent` (`meta`/`tool_start`/`tool_complete`/`tool_error`/`text_delta`/`done`). A persistência de chat-log (agent_runs, chat_messages) mantém-se. `ChatPanel`/`MessageList`/`ToolCard` **não são alterados** (ou alteração mínima de import). _Trace: ADR-9, R5; `useAgentStream.ts:405` é o ponto que muda._

- **AC5 — Escrita end-to-end (caso do bug):** "anota a tarefa de comprar pão" → cria uma `Task` com `titulo: "comprar pão"` em Dexie, visível em `/tarefas`, e o chat confirma. Verificado por teste de integração com `fake-indexeddb`. _Trace: bug origem, AC4 epic._

- **AC6 — Leitura end-to-end:** "quais as minhas tarefas atrasadas?" → o executor corre `listar_atrasadas` com `ctx.db` real, re-injecta o `tool_result` no loop, e o LLM responde com dados reais. Verificado por teste de integração (transport mockado + `fake-indexeddb` semeado). _Trace: ADR-9 (motivação read tools)._

- **AC7 — Confirmação in-process:** `ClientConfirmationProvider` resolve o preview gate sem KV cross-process. Um intent que exija confirmação espera a decisão do utilizador e só então aplica. _Trace: ADR-9, A3, R4._

- **AC8 — Undo client-side:** após uma escrita, existe janela de undo (30s) que reverte a mutação Dexie no cliente (sem `/api/agent/undo`). _Trace: ADR-9, A4, R6._

- **AC9 — Fidelidade de mock (`mock-protocol-fidelity.md`):** os mocks do transport de inferência espelham o wire format SSE real da Anthropic (`content_block_start`/`input_json_delta`/`content_block_stop`/`message_delta`/`message_stop`). Existe ≥1 teste que **falharia** se o protocolo divergisse (ex.: `input_json_delta` fragmentado). E2E (ADR-8) mantém `page.route()` em `/api/anthropic/proxy`. _Trace: `mock-protocol-fidelity.md`, Story 1.2, ADR-8._

- **AC10 — `/api/agent/prompt` deprecated:** o endpoint deixa de ser chamado pelo `useAgentStream`. Marcado deprecated (comentário + log de aviso se invocado). Remoção física só se `@architect` confirmar zero outros callers (senão fica para follow-up). _Trace: A5._

- **AC11 — Regression suite:** a suite de regressão (50 prompts PT-PT, Story 1.10) é adaptada ao novo fluxo client-side e **passa**. Nenhum prompt produz `ctx.db null`. _Trace: Story 1.10, NFR18._

- **AC12 — Qualidade + telemetria:** lint + typecheck + vitest + build PASS. CodeRabbit sem CRITICAL (NFR18). Logs nunca contêm prompt em claro (NFR11 — só hash). Imports absolutos. Zero `any`. Edge (`/api/anthropic/proxy`) continua sem importar Dexie. _Trace: NFR11/15/17/18; CLAUDE.md._
