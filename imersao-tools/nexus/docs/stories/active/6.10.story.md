function buildMimeMessage(to: string, subject: string, body: string): string {
  const mime = [
    `To: ${to}`,
    `Subject: ${subject}`,
    'MIME-Version: 1.0',
    'Content-Type: text/plain; charset=utf-8',
    '',
    body,

### [GAP-6.10-DRAFT-MIME] — encoding MIME para `criar_draft_gmail`

- O encoding proposto é suficiente (MIME simples texto plano)
- `replyToMsgId` (para responder a thread) está no scope desta story ou é deferido

- O subject com caracteres não-ASCII (acentos PT-PT) precisa de encoding adicional no header MIME (RFC 2047 `=?utf-8?B?...?=`)

### [GAP-6.10-PREVIEW-ARCHIVE] — `requiresPreview` para `arquivar_email`

Mas "arquivar email" pode ser considerado mais próximo de uma operação de gestão imediata (menor peso que criar um draft). `@architect` decide com base no precedente 1.6 e na UX esperada.

### [GAP-6.10-KV-STALE] — email arquivado ainda visível no KV
