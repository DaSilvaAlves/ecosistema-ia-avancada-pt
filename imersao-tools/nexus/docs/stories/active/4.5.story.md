**I want** criar, editar e acompanhar as minhas metas (com progresso actual, target numérico ou booleano, prazo, milestones e histórico de updates),

- **AC2 — Helper puro `lib/metas/progress.ts` (tipos e funções base):** Existe `v2/lib/metas/progress.ts` exportando:
  ```ts
  export interface GoalProgressSummary {
    percentage: number;        // 0-100 (capped)
    remaining: number;         // target - current (pode ser 0 se alcançado)
    isAchieved: boolean;       // current >= target (numeric) | status === 'achieved' (boolean)
    milestonesReached: number; // count de milestones com reached: true
    milestonesTotal: number;   // total de milestones
  }
  ```
  Funções exportadas:
  - `getGoalProgress(goal: Goal): GoalProgressSummary` — calcula progresso a partir do estado actual do goal. Para `type: 'boolean'`: `percentage = goal.status === 'achieved' ? 100 : 0`. Para `type: 'numeric'`: `percentage = Math.min(100, Math.round((goal.current / goal.target) * 100))` (defesa: `target <= 0` → 0%). Determinista — não chama `Date.now()`.
  - `formatGoalDeadline(deadline: string | null, todayISO: string): string` — devolve texto PT-PT legível ("sem prazo", "amanhã", "em N dias", "há N dias", etc.). Determinista via `todayISO` por parâmetro.
  Todas as funções são **puras e deterministas** (recebem dados por parâmetro, não lêem `Date.now()` internamente).
  _Trace: FR39/FR40; padrão de `lib/habitos/heatmap.ts` (4.3) e `lib/habitos/metrics.ts` (4.4)._
