## User Story

Como Eurico, quero que na primeira vez que abro o Nexus v2 após login apareça um modal de 4 steps que me permite activar Web Push, ligar Google e configurar Telegram — e que cada step seja saltável —, para que consiga chegar à app funcional sem obrigação de configurar integrações opcionais.

---

## Acceptance Criteria

- **AC1:** `OnboardingModal` abre automaticamente após login se flag `nexus:onboarding:done` não existe no Vercel KV (ou for `false`). Em carregamentos subsequentes não reabre (flag persistida).
- **AC2:** **Step 1** mostra "Olá, Eurico. Vou ser o teu Nexus." com input nome (default "Eurico"). Confirmar nome → avança para Step 2.
- **AC3:** **Step 2** mostra "Preciso de notificar-te de lembretes" com botão "Activar Web Push" que invoca `Notification.requestPermission()`. Se concedido → subscrição Web Push enviada para `/api/push/subscribe` (endpoint pode ser stub nesta story, real em Epic 4). Se negado ou saltado → continua com aviso "Sem push, lembretes só aparecem quando estás na app".
- **AC4:** **Step 3** mostra "Queres ligar Google Calendar/Gmail?" com botão "Ligar Google" (OAuth redirect) e botão "Saltar". Saltar avança para Step 4 sem bloquear.
- **AC5:** **Step 4** mostra "Queres receber lembretes/briefing por Telegram?" com input para token BotFather + instrução PT-PT 3 linhas + botão "Validar" + botão "Saltar". Saltar avança e conclui.
- **AC6:** Ao concluir o Step 4, define `nexus:onboarding:done = true` via KV (ou flag local se KV indisponível em dev). Chat principal fica visível com mensagem de boas-vindas pinned: "Bem-vindo, Eurico. Estou pronto. Escreve qualquer coisa — uma tarefa, uma despesa, um lembrete. Posso processar várias coisas numa só frase."
- **AC7:** Modal ocupa overlay fullscreen (`z-index: 60`) sobre o layout; fundo `rgba(0,0,0,0.8)` + glassmorphism central; navegação por Tab/Enter; Esc NÃO fecha (onboarding deve ser completado).
- **AC8:** Web Push negado: continua sem bloquear, marca `pushDeclined: true` em KV (ou localStorage) para mostrar aviso em Settings depois (UX §1.1 erros).
