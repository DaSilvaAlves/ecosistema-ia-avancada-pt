## User Story (formal)

**As a** utilizador do Nexus,
**I want** abrir uma vista do mês actual que me mostre **quanto entrou**, **quanto saiu**, **onde gastei** (por categoria), **em que dias** (por dia), e a **projecção dos próximos 30 dias** incluindo as recorrentes e as prestações,
**so that** eu saiba para onde o meu saldo caminha — não apenas o que já gastei — e possa agir antes do mês terminar.

## Acceptance Criteria

> Trace: FR21, AC3 do EPIC-3 (projecção 30 dias inclui recorrentes e prestações), AC5 do EPIC-3 (formato PT-PT `€1.234,56`), NFR15 (ESLint+TS strict), NFR17 (cobertura >=60% packages core), NFR18 (CodeRabbit CRITICAL bloqueia), EPIC-3 §8 R5 (checklist a11y stories de UI). Design system: `.claude/rules/design-system-ia-avancada.md`.

- **AC1:** Existe `lib/financas/monthAggregations.ts` — módulo de funções **puras** (sem Dexie, sem React) que exporta:
  - `getMonthBounds(reference: Date): { startISO: string; endISO: string }` — `startISO = YYYY-MM-01`, `endISO = último dia do mês em YYYY-MM-DD`. Usa `date-fns` `startOfMonth`/`endOfMonth` + `format(date, 'yyyy-MM-dd')`. Determinístico (input → output puro; sem dependência de `new Date()`).
  - `getProjectionWindow(reference: Date, days: number = 30): { startISO: string; endISO: string }` — `startISO = reference em YYYY-MM-DD`, `endISO = (reference + days) em YYYY-MM-DD`. Inclusivo em ambos os extremos. Lança `RangeError` PT-PT se `days` não for inteiro `>= 1`.
  - `aggregateInOut(transactions: Transaction[]): { inflowCents: number; outflowCents: number; netCents: number; count: number }` — `inflowCents = Σ amount onde amount > 0`; `outflowCents = Σ amount onde amount < 0` (já vem negativo); `netCents = inflowCents + outflowCents`; `count` = número de transações.
  - `aggregateByCategory(transactions: Transaction[]): Array<{ category: string; sumCents: number; count: number; direction: 'in' | 'out' }>` — agrupa por `category` **e** por direcção (`in` se sum positivo, `out` se sum negativo); ignora categorias com `sumCents === 0`; **ordenado descendente por `Math.abs(sumCents)`**. Devolve array, não Map, para iteração estável.

### Agregações — `monthAggregations.ts`

```typescript
import { startOfMonth, endOfMonth, format } from 'date-fns';
import type { Transaction } from '@/types/db';

const ISO_DAY = 'yyyy-MM-dd';
const MS_PER_DAY = 86_400_000;

export interface MonthBounds {
  startISO: string;
  endISO: string;
}

export interface ProjectionWindow {
  startISO: string;
  endISO: string;
}

export interface InOutTotals {
  inflowCents: number;
  outflowCents: number; // já negativo
  netCents: number;
  count: number;
}

export interface CategoryAggregate {
  category: string;
  sumCents: number;
  count: number;
  direction: 'in' | 'out';
}

export interface DayAggregate {
  dateISO: string;
  inflowCents: number;
  outflowCents: number;
  netCents: number;
  count: number;
}

export function getMonthBounds(reference: Date): MonthBounds {
  return {
    startISO: format(startOfMonth(reference), ISO_DAY),
    endISO: format(endOfMonth(reference), ISO_DAY),
  };
}

export function getProjectionWindow(
  reference: Date,
  days: number = 30,
): ProjectionWindow {
  if (!Number.isInteger(days) || days < 1) {
    throw new RangeError(
      `days deve ser inteiro >= 1 (recebido: ${days})`,
    );
  }
  const start = reference;
  const end = new Date(start.getTime() + days * MS_PER_DAY);
  return {
    startISO: format(start, ISO_DAY),
    endISO: format(end, ISO_DAY),
  };
}

export function aggregateInOut(transactions: Transaction[]): InOutTotals {
  let inflowCents = 0;
  let outflowCents = 0;
  for (const t of transactions) {
    if (t.amount > 0) inflowCents += t.amount;
    else if (t.amount < 0) outflowCents += t.amount; // mantém negativo
  }
  return {
    inflowCents,
    outflowCents,
    netCents: inflowCents + outflowCents,
    count: transactions.length,
  };
}

export function aggregateByCategory(
  transactions: Transaction[],
): CategoryAggregate[] {
  // chave composta: category|direction (para separar in/out da mesma categoria)
  const buckets = new Map<string, CategoryAggregate>();
  for (const t of transactions) {
    if (t.amount === 0) continue;
    const direction: 'in' | 'out' = t.amount > 0 ? 'in' : 'out';
    const key = `${t.category}|${direction}`;
    const existing = buckets.get(key);
    if (existing) {
      existing.sumCents += t.amount;
      existing.count += 1;
    } else {
      buckets.set(key, { category: t.category, sumCents: t.amount, count: 1, direction });
    }
  }
  return Array.from(buckets.values())
    .filter((b) => b.sumCents !== 0)
    .sort((a, b) => Math.abs(b.sumCents) - Math.abs(a.sumCents));
}

export function aggregateByDay(transactions: Transaction[]): DayAggregate[] {
  const buckets = new Map<string, DayAggregate>();
  for (const t of transactions) {
    const existing = buckets.get(t.date);
    if (existing) {
      if (t.amount > 0) existing.inflowCents += t.amount;
      else if (t.amount < 0) existing.outflowCents += t.amount;
      existing.netCents += t.amount;
      existing.count += 1;
    } else {
      buckets.set(t.date, {
        dateISO: t.date,
        inflowCents: t.amount > 0 ? t.amount : 0,
        outflowCents: t.amount < 0 ? t.amount : 0,
        netCents: t.amount,
        count: 1,
      });
    }
  }
  return Array.from(buckets.values()).sort((a, b) => a.dateISO.localeCompare(b.dateISO));
}
```

Funções puras — input → output determinístico. Sem `new Date()` interno (excepto `getProjectionWindow` que recebe `reference: Date` como argumento). Testáveis sem fake timers.
