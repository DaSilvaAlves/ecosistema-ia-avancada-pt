# Story 0.8 — Portar widgets v1 para sidebar v2 com Markets Widget em destaque (UX-4)

**Story ID:** 0.8
**Epic:** 0 — Migração Estrutural
**Status:** Ready for Review
**Bloqueia:** nenhuma story directamente; desbloqueador para Epic 8 Story 8.10 (eliminar v1 só após todos os widgets portados)
**Bloqueada por:** 0.1 (estrutura v2), 0.2 (utilities portadas — `usePomodoro.ts`, `lib/markets/`, `lib/github/`)

---

## User Story

Como Eurico, quero que todos os widgets funcionais do Nexus v1 (Greeting, Pomodoro, GitHub, Quick Links, Goodnight, Morning) estejam portados para a sidebar v2 em `v2/components/widgets/`, e que o MarketsWidget (órfão em v1) seja montado em destaque no topo da sidebar conforme UX-4, para que a sidebar v2 cubra 100% da utilidade actual do dashboard v1 e seja possível avançar para Epic 1 sem depender do v1.

---

## Acceptance Criteria

- **AC1:** `MarketsWidget` está montado no **topo da sidebar** (primeiro elemento abaixo do header), exibindo 9 mercados em formato compacto vertical: CAC40, DAX, DJI, NDX, SP500, BRENT, ETH, NVDA, ASML. Cada linha mostra nome, valor actual e delta vs ontem em percentagem (Lime se positivo, Magenta se negativo). Refresh automático a cada 60s.
- **AC2:** Os seguintes widgets v1 estão portados em `v2/components/widgets/` com a mesma lógica de v1 (sem regressões funcionais): `GreetingWidget`, `PomodoroWidget`, `GitHubWidget`, `QuickLinksWidget`, `GoodnightWidget`, `MorningBriefingWidget` (este último pode ser simplificado — será substituído por Morning Briefing do chat em Epic 1).
- **AC3:** A sidebar exibe os widgets na ordem definida em `front-end-spec-v2.md §3.1`: Greeting + clock → Markets → Pomodoro → GitHub events → Quick Links → Goodnight (condicional por hora).
- **AC4:** `BriefingWidget.tsx` e `FeedWidget.tsx` (ficheiros órfãos de v1, listados como `🟡` em PRD §2.1) são **eliminados** de `v2/components/widgets/` — NÃO são portados (PRD §2.1 diz "Apaga"). Esta eliminação afecta apenas `v2/` — `src/` v1 fica intocado.
- **AC5:** `PomodoroWidget` suporta modo "Ligar a tarefa?" com select dropdown de tarefas Dexie (via `useLiveQuery` de `dexie-react-hooks`). Se Dexie ainda não tem tarefas (Story 0.3 instalou schema vazio), dropdown mostra "Sem tarefas ainda" sem crash.
- **AC6:** `MarketsWidget` usa a lib `lib/markets/` portada de v1 (Yahoo Finance via allorigins.win, conforme `architecture-v2.md §3` nota `# PORTADO de v1`). Se fetch falhar, exibe skeleton Cyan pulsing com texto "Indisponível" — não lança erro para o utilizador.
- **AC7:** Sidebar hidde em `<1024px` conforme `front-end-spec-v2.md §2.3` (responsive) — em mobile a sidebar colapsa para drawer.
- **AC8:** Nenhum ficheiro em `imersao-tools/nexus/src/` é modificado (verificável via `git diff --name-only`).
