## User Story

Como Eurico, quero ter a estrutura base do Nexus v2 criada em `imersao-tools/nexus/v2/` com Next.js 15 App Router, TypeScript strict e Tailwind 4, paralela ao v1 existente em `imersao-tools/nexus/src/`, para que o @dev possa arrancar o desenvolvimento v2 sem destruir o que está funcional.

---

## Acceptance Criteria

- **AC1:** Directório `imersao-tools/nexus/v2/` existe com `package.json` próprio; `imersao-tools/nexus/src/` está intocado (zero ficheiros modificados, verificável via `git diff --name-only`).
- **AC2:** `npm run build` executado dentro de `v2/` compila sem erros TypeScript nem erros de lint.
- **AC3:** `tsconfig.json` em `v2/` tem `"strict": true`, `"baseUrl": "."` e path alias `"@/*": ["./*"]`.
- **AC4:** Tailwind 4 configurado em `v2/tailwind.config.ts` e `v2/styles/globals.css` com custom properties do design system [IA]AVANÇADA PT: `--color-background: #04040A`, `--color-white: #F0F4FF`, `--color-cyan: #00F5FF`, `--color-gold: #FFB800`, `--color-purple: #9D00FF`, `--color-magenta: #FF006E`, `--color-lime: #39FF14`.
- **AC5:** `v2/app/layout.tsx` define `<html lang="pt-PT">`, fundo `#04040A`, e importa fontes Inter + JetBrains Mono via `next/font/google`.
- **AC6:** `v2/.env.example` lista as 12 variáveis de ambiente necessárias (arch §9.2) com descrições PT-PT, sem valores reais.
- **AC7:** `npm run dev` dentro de `v2/` arranca servidor em porta distinta de v1 (ex: 3001) sem conflitos.
- **AC8:** `v2/next.config.ts` define security headers (arch §9.4): `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`.

## Anti-padrões (explícitos para esta story)

- **NÃO** inicializar v2 dentro de `nexus/src/` — deve ser `nexus/v2/` paralelo
- **NÃO** tocar em `imersao-tools/nexus/src/` (v1 intocado — `architecture-v2.md §3`)
- **NÃO** usar light mode — fundo sempre `#04040A` (`design-system-ia-avancada.md`)
- **NÃO** usar localStorage para dados do Nexus — apenas para `auth.session`, `ui.theme`, `chat.draft` (ADR-2, Dexie 4 para o resto)
- **NÃO** usar Lexical como editor markdown (ADR-3 decidiu Tiptap 2)
- **NÃO** mencionar Jarvis em nenhum ficheiro (Constraint C11)
- **NÃO** usar cores arbitrárias — apenas as 9 cores do sistema ([IA]AVANÇADA PT)
- **NÃO** usar fontes além de Inter e JetBrains Mono
