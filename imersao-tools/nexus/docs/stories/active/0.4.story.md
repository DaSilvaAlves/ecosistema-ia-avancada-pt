# Story 0.4 — Layout chat-first (UX §2 + §3.1) com chat metade esquerda + sidebar 360px

**Story ID:** 0.4
**Epic:** 0 — Migração Estrutural
**Status:** Ready for Review
**Bloqueia:** 0.7 (OnboardingModal sobrepõe este layout), 0.8 (widgets vão na sidebar deste layout), Epic 1 (chat UI completa)
**Bloqueada por:** 0.1 (estrutura v2), 0.2 (themes e hooks), 0.3 (schema Dexie disponível)

---

## User Story

Como Eurico, quero ver o ecrã principal do Nexus v2 com o chat a ocupar a metade esquerda e a sidebar de widgets à direita (360px fixa), com input sempre visível em baixo, para que a interface comunique desde o primeiro momento que "chat-first" é o paradigma central.

---

## Acceptance Criteria

- **AC1:** `app/(app)/page.tsx` renderiza layout com `ChatPanel` (flex 1, esquerda) e `Sidebar` (360px fixa, direita), conforme wireframe `front-end-spec-v2.md §3.1`.
- **AC2:** `Header` sticky (h:56px, fundo glassmorphism `rgba(255,255,255,0.025)` + `backdrop-filter: blur(12px)`) com logo "⚡ NEXUS" e links de navegação [Tarefas][Finanças][Hábitos][Diário][⚙️].
- **AC3:** `InputBox` sticky bottom (h min:64px, max:200px, fundo `rgba(255,255,255,0.04)`) com textarea autosize, botão de anexo 📎, botão de voz 🎙️, e botão enviar ⏎. Atalhos: `/` foca input, `↵` envia, `⇧↵` nova linha.
- **AC4:** `Sidebar` (w:360px, h:100vh-56px, fundo glassmorphism, scroll independente) escondida em viewport < 1024px.
- **AC5:** Comportamento responsive: >= 1280px layout completo; 1024-1279px sidebar reduz para 320px; 768-1023px sidebar vira drawer escondido com botão "☰"; < 768px chat fullscreen com drawer.
- **AC6:** Fundo da página é `#04040A` — zero áreas com cor clara visível.
- **AC7:** `ChatPanel` mostra mensagens em lista vertical (scroll), com bolhas de utilizador alinhadas à direita (fundo `rgba(0,245,255,0.08)`) e bolhas do agente à esquerda.
- **AC8:** `app/(app)/layout.tsx` aplica o layout apenas a rotas autenticadas; redireciona para `/login` se sem sessão (placeholder, auth real em Story 0.6).

## Anti-padrões (explícitos para esta story)

- **NÃO** usar light mode ou fundo claro em nenhum componente
- **NÃO** usar cores fora da paleta [IA]AVANÇADA PT (9 cores + variações de opacidade)
- **NÃO** usar gradientes fora dos 3 permitidos (`front-end-spec-v2.md §5.5`)
- **NÃO** usar fontes além de Inter e JetBrains Mono
- **NÃO** usar ícones além de lucide-react (UX §5.6 — única lib de ícones)
- **NÃO** implementar lógica de chat real nesta story — apenas UI estática com dados mock
- **NÃO** implementar auth real — Story 0.6 é responsável por isso
- **NÃO** reabrir UX-1 (chat sempre visível, sidebar 360px) — decisão UX fechada
