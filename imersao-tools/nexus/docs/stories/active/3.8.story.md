### Cálculo de fatura (revisão manual obrigatória — §9)

Dado `Card { closingDay, dueDay }` e uma data de referência `today`:

**Fatura corrente** = transações com `cardId == X` E `date` no intervalo `[ultimoFecho, proximoFecho)`:
- `ultimoFecho`: o `closingDay` mais recente antes ou igual a `today`. Se hoje é 25/05 e `closingDay=15`, então `ultimoFecho = 15/05/2026`.
- `proximoFecho`: o `closingDay` do mês seguinte. Se `ultimoFecho = 15/05`, então `proximoFecho = 15/06/2026`.
- Intervalo: `[15/05/2026, 14/06/2026]` (inclusivo em ambos os extremos — nota: a transação do dia de fecho entra na **fatura seguinte**, portanto o intervalo correcto é `[ultimoFecho, proximoFecho)` exclusivo no limite superior, ou seja `[15/05, 14/06]` inclusivo).

**Próxima fatura** = transações com `cardId == X` E `date` no intervalo `[proximoFecho, fechoSeguinte)`:
- `proximoFecho = 15/06/2026`, `fechoSeguinte = 15/07/2026`.
- Intervalo: `[15/06/2026, 14/07/2026]` inclusivo.

**Edge case `closingDay=31`** em meses curtos:
- Fevereiro (28/29 dias): clamp ao último dia do mês, análogo ao `installmentDates` da Story 3.6.
- Ex: `closingDay=31`, `today=25/02/2026` → `ultimoFecho = 31/01/2026` (Janeiro tem 31d) → `proximoFecho = 28/02/2026` (clamp Feb não-bissexto).

**Exemplo canónico (para o AC e para a revisão manual §9):**

| Input | Resultado |
|-------|-----------|
| `closingDay=15`, hoje=25/05/2026 | Corrente: `15/05→14/06`; Próxima: `15/06→14/07` |
| `closingDay=1`, hoje=15/05/2026 | Corrente: `01/05→31/05`; Próxima: `01/06→30/06` |
| `closingDay=31`, hoje=15/02/2026 | Corrente: `31/01→27/02`; Próxima: `28/02→30/03` |
| `closingDay=15`, hoje=15/05/2026 (dia de fecho) | Corrente inicia hoje: `15/05→14/06`; Próxima: `15/06→14/07` |

> **Nota §9:** o gate `@dev` valida esta tabela de casos cruzando com os ACs — a função `getBillingPeriods` deve produzir exactamente estes resultados para cada input.

## User Story (formal)

**As a** utilizador do Nexus,
**I want** ver, para cada cartão de crédito, o valor da fatura corrente, o valor estimado da próxima fatura, e a lista de compras parceladas activas vinculadas a esse cartão,
**so that** eu saiba exatamente o que devo pagar na próxima liquidação e que compromissos futuros já tenho assumidos em cada cartão.

const ISO_DAY = 'yyyy-MM-dd';

/** Clamp day to last valid day of the month. */
function clampDay(year: number, month: number, day: number): Date {
  const d = new Date(year, month, 0); // último dia do mês (month é 1-indexed)
  return new Date(year, month - 1, Math.min(day, d.getDate()));
}

  if (!Number.isInteger(closingDay) || closingDay < 1 || closingDay > 31) {

  }

export function countInstallmentPayments(
  startDate: string,
  n: number,
  reference: Date,
): InstallmentProgress {
